Issue #0013 — Foundation product surfaces — 2026-08-09

Design Decisions

Decision Compose existing Foundation stores

Dashboard, Project Overview, Assets, and Tasks consume the established Project, Asset, and Task modules without introducing a parallel page-owned data layer.

Decision Explicit operational feedback

Every data region renders loading, empty, error, and success states. Upload, cancellation, settings save, and connection checks expose pending and failure feedback.

Decision Preserve secret boundaries

Settings restores only non-sensitive connector fields from the server. Credential inputs stay outside React and Zustand state and are never repopulated.

None.

Tradeoffs

Foundation-only module entry points

Ideas, Topics, and Scripts remain clearly labelled future module destinations; their workflows are intentionally not implemented in this issue.
